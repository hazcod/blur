# Vendored dependency patches

`vendor/` is generated by `go mod vendor`. Keep upstream source changes narrow,
document each one here, and retain this file when refreshing dependencies.

## github.com/golang-gui/goui v0.6.0

The app uses a small local patch because upstream v0.6.0 references
`syscall.SYS_PIPE` and `syscall.SYS_POLL`, which are unavailable on Linux arm64.
The vendored Linux libc wrapper now uses the already-required
`golang.org/x/sys/unix` `Pipe` and `Poll` APIs. The X11 event loop reads the
`unix.PollFd.Revents` field spelling. This keeps syscall-number selection in
the maintained architecture-aware dependency and avoids adding another
graphics backend or changing Blur's UI API.

The regression gate is `make cross-build cross-test-compile`; it compiles the
actual Linux arm64 desktop and adapter tests with cgo disabled. Linux runtime
pipe/poll behavior is covered by `TestNativeEventPipePollsReadableAfterWrite`
on native Linux CI. Cross-compilation is not a substitute for ARM64 runtime or
X11 desktop validation.

When upstream includes an equivalent fix, remove the local patch and vendor
the released upstream version after the same architecture and runtime checks
pass.

## Dependency refresh note

`go mod vendor` restores upstream source and removes both patches above. After
refreshing vendor, reapply them and run the documented cross-build gates before
shipping; the normal host test suite does not compile the Windows UIA or Linux
arm64 UI paths.

## github.com/lpintes/walk v0.0.0-20261029133242-6a00370d773d

Blur uses only `walk/uia`'s passive UI Automation connection, control-view
walker, property reads, and release lifecycle. The dependency's default UIA
provider transaction timeout is 20 seconds, which exceeds Blur's 750 ms
capture deadline. The vendored `Automation` now sets a 200 ms transaction
timeout during MTA initialization and fails closed if the property cannot be
set. `Element.TextBounded` uses `TextRange.GetText(maxLength)` so UIA bounds
the returned UTF-16 range before allocation; Blur deliberately does not call
the unbounded `ValuePattern.Value` API. Blur also wraps calls in caller
deadlines, serializes them on the library's locked COM worker, releases late
interface results, and joins outstanding calls before closing that worker.

Element cleanup uses the dependency's nonblocking `Element.ReleaseLater` queue
so a stalled provider cannot make frame cleanup block Pause or shutdown. Queued
releases are drained by the Automation worker before its next call or during
close. The regression gates are host-runnable Windows policy tests plus
Windows amd64 cgo-disabled cross-compilation. These do not prove provider
timeout, COM cleanup, or capture behavior on Windows; a native synthetic UIA
fixture and Windows CI runtime test remain release gates. The upstream license
and attribution files are retained under `vendor/github.com/lpintes/walk/`.
