# Security policy

Blur handles potentially sensitive personal data. Treat privacy and security
issues as high priority and avoid including captured content, credentials, or
personal data in public reports.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's advisory
form for this repository:
https://github.com/nielsgroen/blur/security/advisories/new

Private vulnerability reporting must be enabled for the repository before
public release. Include the affected version or commit, platform, steps to
reproduce, and potential impact. Do not publish details before coordinating a
fix. This repository path is a temporary OSS identity and may change before
the first public release.

## Scope

Relevant reports include unauthorized access to local memory, unintended data
egress, insecure credential handling, unsafe capture or injection behavior,
and vulnerabilities in build or release workflows. Blur does not yet ship a
released desktop application; reports about planned behavior are welcome as
design feedback.
